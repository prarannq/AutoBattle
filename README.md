# AutoBattle

Unityで制作した2Dオートバトルゲームです。
ユニットの編成、配置、アイテムの組み合わせを決め、全9ラウンドの自動戦闘を行います。

企画、ゲーム設計、Unityでの実装、サーバー連携まで、一人で開発しました。
※コードや開発補助として生成AIを使用しました。

## ゲーム内容

* 最大6体のユニットでチームを編成
* ユニットを2×3のフィールドに配置
* ショップでアイテムを購入・リロール
* 戦闘は自動で進行
* 通常攻撃でMPがたまるとスキルを発動
* 全9ラウンドで進行
* 3回敗北するとゲーム終了

## 開発情報
* 開発人数：1人
* ゲームエンジン：Unity 2021.3.8f1
* 使用言語：C#、PHP、Python
* インフラ：AWS EC2、Amazon RDS

## 実装した内容

* ユニットの選択、配置、移動
* ショップとアイテム購入
* 通常攻撃、スキル、ダメージ、死亡処理
* ラウンド進行と勝敗判定
* JSONによるユニット・アイテムデータの管理
* サーバーとのデータ送受信
* 過去のプレイヤー編成を敵として取得する非同期対戦
* プレイヤーの操作や戦闘結果の記録
* 記録したデータを利用した勝率予測機能の作成

サーバー連携

Unity WebGLからAWS上のAPIへHTTP通信を行っています。

```text
Unity WebGL
    ↓ HTTP通信
AWS EC2上のAPI
    ├─ PHP
    │   ├─ プレイヤー登録
    │   ├─ 対戦結果・操作ログの保存
    │   ├─ 過去のプレイヤー編成の取得
    │   └─ ユニット・アイテムの統計情報の取得
    │
    └─ Python
        └─ 現在の編成の勝率推定
Amazon RDS
    └─ プレイヤー情報、編成、アイテム、対戦結果などを保存
```
過去のプレイヤーが使用した編成をデータベースから取得し、現在のプレイヤーの対戦相手として使用しています。
Pythonを用いてプレイヤーの勝率を予測する機能ではデータベースの情報を使用しています。
プレイヤーが確認できるデータページにもデータベースの情報を使用し、各ユニットやアイテムの勝率などを確認できます。

※サーバー側のプログラムと実際の接続情報は、このリポジトリには含まれていません。

## 工夫した点

ユニットやアイテムの能力値をJSONで管理し、コードを直接変更しなくても、数値の調整やデータの追加を行えるようにしました。
また、攻撃対象の選択、効果の適用、戦闘中のイベント処理を分け、ユニットやアイテムを追加しやすい構成を目指しました。
ゲーム部分だけでなく、サーバー通信、データベースへの保存、過去データを利用した非同期対戦まで、一つのシステムとして動作させることを目標に開発しました。
ゲームを公開しているページの右上からデータページを開けるようにし、オンライン対戦ゲームでは重要な各ユニットやアイテムの勝率などを別のタブで確認しながらゲームを進行できるようにしました。
